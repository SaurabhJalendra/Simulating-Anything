Simulating Anything
===================

A multi-agent scientific discovery engine. Given a natural language description
of any phenomenon, the system automatically builds a simulation, trains a world
model, explores the parameter space, and extracts human-interpretable
discoveries -- governing equations, phase boundaries, scaling laws, and optimal
strategies.
