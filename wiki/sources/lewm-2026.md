# LeWorldModel: Stable End-to-End Joint-Embedding Predictive Architecture from Pixels

**Authors:** Lucas Maes (lead), Quentin Le Lidec, Damien Scieur, Yann LeCun, Randall Balestriero
**Affiliations:** Mila / Université de Montréal, NYU, Samsung SAIL, Brown University
**arXiv:** [2603.19312](https://arxiv.org/abs/2603.19312) (submitted Mar 13 2026, revised Mar 24 2026)
**Project:** [le-wm.github.io](https://le-wm.github.io/)
**Code:** [github.com/lucas-maes/le-wm](https://github.com/lucas-maes/le-wm)
**Data:** [hf.co/collections/quentinll/lewm](https://hf.co/collections/quentinll/lewm)

## One-line claim

First JEPA that trains stably end-to-end from raw pixels using only two loss terms — no stop-gradient, no EMA target encoder, no auxiliary supervision.

## Architecture

- **Latent:** 192-dim token (~200× fewer tokens than DINO-WM)
- **Parameters:** ~15M
- **Encoder:** maps observation → `z_t`
- **Predictor:** takes (latent, action) → predicts `ẑ_{t+1}`

## Two loss terms

```
L_LeWM = L_pred + λ · SIGReg(Z)
```

1. **L_pred** — standard latent prediction loss
2. **SIGReg** — Sketched Isotropic Gaussian Regularizer (the anti-collapse trick). Defined in the companion [LeJEPA](#concepts/jepa) paper. Enforces Gaussian-distributed latent embeddings.

Reduces tunable hyperparameters from six (in prior end-to-end JEPA alternatives) to one.

## Stability

The historical JEPA pain point is representation collapse. Prior fixes required stop-gradient, EMA, momentum schedules, asymmetric losses, or pretrained encoders. LeWM eliminates all of these — collapse is prevented purely by SIGReg's Gaussian-distribution constraint on the latent.

## Training cost

- Single GPU, "a few hours"
- Datasets: Two-Room (2D nav), Reacher (2-joint arm), Push-T (block manipulation), OGBench-Cube (3D pick-and-place)

## Empirical results

| Metric | Value |
|---|---|
| Planning speed | **48× faster** than DINO-WM (~1s vs 47s per plan) |
| Push-T agent location probe | MSE 0.052 |
| Push-T block angle probe | r = 0.902–0.999 |
| Surprise-based detection | reliably flags physically implausible events |

## Limitations (acknowledged by authors)

- **Underperforms on Two-Room** — task has very low intrinsic dimensionality, hindering the Gaussian regularizer
- **Gap vs DINO-WM on OGBench-Cube** — DINO-WM benefits from large-scale pretrained visual prior

## Why it matters for Simulating-Anything

This is the **first published JEPA with quantitative evidence that latents recover physical quantities** (position, orientation) end-to-end from pixels at a hardware envelope (15M params, single GPU) compatible with the project's RTX 5090 setup. Direct candidate for replacing or augmenting RSSM in the discovery pipeline.

**Critical caveat:** all probing was on robotics control tasks. No published evidence yet that JEPA latents factorize physical quantities for chaotic dynamical systems (Lorenz, Brusselator) or for equation recovery via SINDy/PySR. Treat any LeWM integration as a research bet pending A/B validation.
